### 메뉴 sort_no 인코딩

`sort_no = 대(1~9) × 1000 + 중(0~9) × 100 + 소(0~99)` → 범위 약 `1001`~`9999`.

| 대 | 의미 | 대 폴더 sort |
|----|------|--------------|
| 1 | 오늘 할 일 | `1001` (최상위 leaf) |
| 2 | 문서 | `2000` |
| 3 | 문서 현황·결재 | `3000` |
| 5 | 기초정보 | `5000` |
| 6 | 시스템 | `6000` |

중 폴더는 `대*1000 + 중*100` (예: CCP `2100`), 소는 그 아래 `+1`~`+99` (예: `2101`).  
조회·메뉴관리 목록은 **이 sort_no 순**만 사용한다 (`sp_tbl_menu_sort_encode_u_000`).

## 사용양식 관리 편집 규칙 (`hwp-template-management`)

| 컬럼 | 추가 | 이후 |
|------|------|------|
| 양식코드 | 수정 가능 | 변경 불가 |
| 양식명 | 가능 | 가능 |
| 타입 | hwp 고정 | 변경 불가 |
| 구분(`sys_yn`) | `usr` 고정 — 화면 콤보 없음(badge 표시) | 변경 불가 |
| 사용여부 | 가능 | 가능 |

- 삭제는 자사양식(`usr`)만. 시스템양식은 FE·Service·SP 3중 차단(문구 통일: *"시스템에서 제공하는 양식은 삭제할 수 없습니다."*)
- 파일 기능(업로드·내보내기·불러오기·초기화)은 구분과 무관하게 허용
- 업로드는 덮어쓰지 않고 `tbl_company_template_file` 에 버전 1건을 쌓는다 — 파일명 뒤에 `_yyyyMMddHHmmss`
- 초기화 = `default_file_idx` 복원(시스템양식은 배포 원본, 자사양식은 최초 등록본)

## 문서주기 (`schedule-cycle-management`)

- **양식 1개 = 주기 0..1건** — `tbl_schedule_rule UNIQUE(co_cd, tmpl_cd)`
- 주기 `cycle_cd`: 매일/매주/매월/분기/반기/매년 = `D`/`W`/`M`/`Q`/`H`/`Y` (기존 대문자 도메인 유지, `E` 수시는 화면 제외)
- 반복 상세 `tbl_schedule_rule_detail.detail_ty`: `week-day` / `month-day` / `month-end` / `quarter-month` / `half-month` / `year-month`
- 비영업일 처리 `nonwork_rule`: `keep`(그대로) / `prev`(이전 영업일) / `next`(다음 영업일) — 현재 토·일만 비영업일
- 관리 시작일 `base_dt`: `yyyyMMdd` 저장, 화면은 `input type="date"`
- 마감시간 `due_time`: `HHMM` 저장, 화면은 `input type="time"`. 알림은 `alarm_dt = 마감 - app.schedule.alarm-before-minutes`
- 담당부서·담당자는 **코드·ID로만 저장**(`dept_cd`·`user_id`), 이름은 조회 시 조인 표시
- 예정일 계산은 Java `CycleScheduleGenerator` 한 곳 — 31일 지정은 말일로 당기고, 시작일 이전은 만들지 않는다
