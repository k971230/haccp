## 문서가 아닌 정본

문서보다 **코드·규칙 파일이 먼저**다. 아래가 어긋나면 문서가 틀린 것이다.

| 정본 | 무엇 |
|---|---|
| `.cursor/rules/*.mdc` | 작업 규칙. `CLAUDE.md`·`AGENTS.md` 는 여기를 가리킬 뿐이다 |
| `frontend/haccp-web/src/shell/tabRoute.ts` | 화면 28개의 URL |
| `db_sasshaccp/` 6본 | 스키마·SP·기초데이터 |
| 각 폴더의 `README.md` | 그 폴더가 무엇을 맡고 무엇을 안 맡는지 |
| 소스 주석 | 왜 그렇게 했는지 |
