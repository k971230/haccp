## 찾는 순서

1. 화면이면 `scrnCd` → `shell/screenRegistry.tsx` → `pages/{대}/{중}/` README. 경로 [`24`](24_URL_DB_폴더_패키지_정본.md)  
2. HTTP면 `src/api/` → 주석의 `/api/v1/...` → BE Controller `@RequestMapping`  
3. SP면 `resources/mapper/{대}/{중}/` XML 의 `sp_*`  
4. 태그면 `docs/23`

## 골드 위치

| 역할 | 경로 |
|------|------|
| 셸 | `frontend/haccp-web/src/shell/HaccpShell.tsx` |
| 탭 URL | `shell/tabRoute.ts` · `stores/tabStore.ts` |
| 로그인 | `pages/auth/LoginPage.tsx` · `com.haccp.auth.AuthService` |
| DocForm 골드 | `pages/docs/ccp/ColdMonitorPage.tsx` |
| 삭제 골드 | `com.haccp.docs.documents.DocumentService` · `mapper/docs/documents/DocumentMapper.xml` |
| sys 분할 골드 | `pages/sys/README.md` |
| docs 분할 골드 | `pages/docs/README.md` |

## FE `src/` 의존 방향

```
pages ──► api / hooks / components / shell / lib / stores / types / config
shell ──► api / stores / lib / hooks(일부)     ※ pages import 금지 (screenRegistry만 예외)
api   ──► http / types / config                ※ UI·toast 금지
```

진입: `main.tsx` [HF1] → `routes/AppRoutes.tsx` [HF2] → `HaccpShell` [HF49].

## BE

`com.haccp.{대}.{중}` → Controller → Service → Mapper XML → SP.  
문서는 `com.haccp.docs.{중}` (`document` · `template` · `hwp` · `ccp` · `sch` · `prp` …). `com.haccp.doc` 없음.

## 평탄 vs 분할

`pages/{대}/{중}/` 가 정본이다. 중 아래 화면이 하나면 `{메뉴}` 단을 생략한다. 아직 평탄하면 **손대는 메뉴만** 그 작업에서 나눈다.
