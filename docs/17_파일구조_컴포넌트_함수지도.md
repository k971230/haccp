# HACCP 파일 찾는 법

> 정본: `17_파일구조_컴포넌트_함수지도.md`  
> 작성일: 2026-08-21 · 개발자: 박승우  
> **전수 트리는 두지 않는다.** 트리는 곧 코드와 어긋난다. 태그→파일은 [`23_PIPELINE.md`](23_PIPELINE.md). 화면 체인은 도메인 README.

## 찾는 순서

1. 화면이면 `scrnCd` → `shell/screenRegistry.tsx` → `pages/{영역}/` README  
2. HTTP면 `src/api/` → 주석의 `/api/v1/...` → BE Controller `@RequestMapping`  
3. SP면 `resources/mapper/{영역}/` XML 의 `sp_*`  
4. 태그면 `docs/23`

## 골드 위치

| 역할 | 경로 |
|------|------|
| 셸 | `frontend/haccp-web/src/shell/HaccpShell.tsx` |
| 탭 URL | `shell/tabRoute.ts` · `stores/tabStore.ts` |
| 로그인 | `pages/auth/LoginPage.tsx` · `com.haccp.auth.AuthService` |
| DocForm 골드 | `pages/ccp/ColdMonitorPage.tsx` |
| 삭제 골드 | `com.haccp.docs.document.DocumentService` · `mapper/docs/document/DocumentMapper.xml` |
| sys 분할 골드 | `pages/sys/README.md` |
| docs 분할 골드 | `pages/docs/README.md` |

## FE `src/` 의존 방향

```
pages ──► api / hooks / components / shell / lib / stores / types / config
shell ──► api / stores / lib / hooks(일부)     ※ pages import 금지 (screenRegistry만 예외)
api   ──► http / types / config                ※ UI·toast 금지
```

진입: `main.tsx` [HF1] → `routes/AppRoutes.tsx` [HF2] → `HaccpShell` [HF49].

## BE

`com.haccp.{영역}` → Controller → Service → Mapper XML → SP.  
문서는 `com.haccp.docs.{메뉴}` (`document` · `template` · `hwptemplate` …). `com.haccp.doc` 없음.

## 평탄 vs 분할

sys·docs 는 화면 폴더가 있다. ccp·hyg·bas·tsk·ops·auth 는 평탄 — 체인 표는 그 도메인 README. 손대는 메뉴만 그 작업에서 나눈다.
