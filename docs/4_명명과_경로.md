# 4. 명명과 경로

> 개발자: 박승우 · 일자: 2026-08-26
> 규칙의 강제는 `.cursor/rules/01-project-core.mdc`. 여기는 **왜 그런지와 예외**를 적는다.

---

## 1. 한 줄 규칙

**URL = DB = 폴더 = 패키지.**

`/haccp` 와 `/api/v1` 바로 다음이 **대분류 / 중분류 / 화면코드** 순으로 같다.

```
URL   /draft/ccp-monitoring/ccp-htg
DB    tbl_menu   draft → ccp-monitoring → ccp-htg
FE    frontend/haccp-web/src/pages/draft/ccp-monitoring/
BE    com.haccp.draft.ccpmonitoring
XML   backend/haccp-api/src/main/resources/mapper/draft/ccpmonitoring/
```

한글 메뉴명은 URL 에 넣지 않는다.
Vite·Router basename 은 `/haccp/` 이고, 라우터 pathname 과 API 경로에는 `/haccp` 를 **다시 넣지 않는다.**

---

## 2. 왜 이렇게 하나

화면 하나가 일곱 층에 걸쳐 있다. 층마다 이름이 다르면 「이 화면의 서버 코드가 어디냐」를
매번 찾아야 하고, 옮길 때 한 층이 빠진다.

실제로 그런 사고가 있었다 — 패키지를 옮기면서 매퍼 XML 의 `resultType` 을 안 옮겨
기동이 안 됐다. **매퍼 XML 은 컴파일에 안 잡힌다.**

---

## 3. 자바 패키지의 예외 하나

자바 패키지는 하이픈을 못 쓴다. **중분류의 하이픈만 지운다.**

| URL 중분류 | 패키지 |
|---|---|
| `ccp-monitoring` | `ccpmonitoring` |
| `html-form` | `htmlform` |
| `hwp-doc` | `hwpdoc` |

그 밖의 차이는 규칙 위반이다. 2026-08-26 에 셋을 맞췄다.

| 전 | 후 | 왜 |
|---|---|---|
| `draft.hwp` | `draft.hwpdoc` | URL 이 `hwp-doc` 인데 패키지만 `hwp` 였다 |
| `docs.document` | `docs.documents` | URL 이 `/docs/documents` (복수) |
| `docs.template` | `docs.templates` | URL 이 `/docs/templates` (복수) |

**단수·복수도 맞춘다.** 예외를 두면 다음 사람이 어느 쪽인지 매번 확인해야 한다.

---

## 4. 절대 안 바꾸는 것

| 값 | 어디 | 바꾸면 |
|---|---|---|
| `scrnCd` | `tbl_screen`·`tbl_menu`·`SCREEN_PATH` | 권한·메뉴·통계가 끊긴다 |
| `persistId` | 그리드 열 설정 키 | 사용자가 저장한 열 너비가 날아간다 |

폴더·URL 이 바뀌어도 이 둘은 그대로 둔다.

---

## 5. 코드값 표기

| 대상 | 표기 | 예 |
|---|---|---|
| 경로에 실리는 값 (`scrn_cd`·`menu_cd`·`tmpl_cd`) | 소문자·하이픈 | `ccp-htg` · `tml_ccp_htg_001` |
| 공통코드 `main_cd` | UPPER_SNAKE | `DOC_STATUS` · `HTML_INPUT_TY` |
| 공통코드 `sub_cd` | UPPER_SNAKE | `WRK` · `KEEP` · `RADIO` |

**`sub_cd` 는 업무 표에 저장되는 값과 같은 표기다.**
`tbl_schedule_rule.nonwork_rule = 'KEEP'` 이면 `sub_cd` 도 `KEEP` 이다.

코드만 바꾸고 데이터를 안 바꾸면 라벨이 안 붙어 **콤보가 빈 값**이 된다. 항상 같이 옮긴다.

## 8. 화면 코드를 정할 때

```
1. 이미 있는 화면인가          3_화면_지도.md 를 본다
2. 어느 대·중분류에 들어가나    tbl_menu 트리를 본다
3. 그 칸에서 유일한가          tbl_menu 는 UNIQUE (co_cd, menu_cd) 다 —
                              메뉴코드는 트리 전체에서 유일해야 한다
4. 한 번 정하면 안 바꾼다
```

중분류 아래 화면이 하나뿐이면 중분류 단을 생략해도 된다.
**미리 전 메뉴를 나누지 않는다** — 이번에 손대는 메뉴만 이 칸으로 옮긴다.

---

## 9. 하드코딩하지 않는 것

값을 조건문에 나열하면 그 값이 늘 때 조용히 빠진다. 실제로 그랬다.

```sql
-- 하지 않는다: 새 양식이 목록에서 사라진다
WHERE tmpl_cd ~ '^hwp_sys_0(0[1-9]|1[0-9]|2[0-7])$'

-- 한다: 값으로 판단한다
WHERE t.doc_kind = 'HWP'
```

`hwp_sys_028`~`038` 열한 종이 이 정규식 밖이라 화면에 안 보였다.
