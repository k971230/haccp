# 3. 화면 지도

> 개발자: 박승우 · 일자: 2026-08-26
> **28화면**이 각 층에서 어디에 있는지. `tbl_menu`(0000) 기준으로 뽑았다.

화면 하나를 고칠 때 이 표에서 줄을 찾아 그 화면이 걸친 층을 먼저 본다.
만드는 법은 [`2_화면_추가하기.md`](2_화면_추가하기.md).

**이 표는 손으로 고치지 않는다.** DB·`tabRoute.ts`·컨트롤러에서 뽑는다 —
손으로 적으면 화면이 하나 늘 때마다 어긋난다.

읽는 법

- **전용 SP** 는 `sp_{scrnCd}_*` 만 센 것이다. 0 이어도 공용 SP(`sp_tbl_*`)를 쓴다
- **BE Controller** 가 「공용」이면 그 화면만의 컨트롤러가 없다는 뜻이다.
  결재 3화면·문서함은 문서 허브(`DocumentController`)를, 오늘 할 일·이탈은
  `TaskController` 를 나눠 쓴다
- HTML 양식 원본 5화면은 `HtmlTemplateController` 하나가 `@RequestMapping({...})`
  배열로 다섯 경로를 함께 받는다. 지면 구조만 다르고 동작이 같아서다

## 화면이 아닌 API

화면 없이 도는 것들이다. 지우지 않는다.

| URL | 무엇 | 왜 화면이 없나 |
|---|---|---|
| `/api/v1/auth/**` | 로그인·로그아웃 | 인증 전 경로 |
| `/api/v1/menu/list` | 좌측 메뉴 트리 | 셸이 쓴다 |
| `/api/v1/code` | 공통코드 콤보 | 화면마다 쓴다 |
| `/api/v1/pref/grid/**` | 그리드 열 설정 | 사용자별 저장 |
| `/api/v1/log/view/collect` | 화면 체류 로그 | 셸이 모아 보낸다 |
| `/api/v1/docs/templates/**` | HWP 양식 원본 파일 | 사용양식관리 화면이 쓴다 |
| `/api/v1/tsk/notifications/**` | 알림 | 현재 화면에서 안 부른다 |
| `/api/v1/docs/documents/{idx}/relations/**` | 문서 관계 | 문서함이 조회만 한다 |
| `/api/v1/docs/audit-export/**` | 감사자료 내보내기 | **의도적 보존** — 규제·감사 대비. `@Deprecated` 로 표시만 하고 지우지 않는다 (`tbl_audit_log` 와 다른 기능이다) |

## 다시 뽑는 법

```sh
# 화면·메뉴
psql -c "SELECT menu_cd, menu_nm, h_menu_cd, scrn_cd FROM sasshaccp.tbl_menu WHERE co_cd='0000' ORDER BY sort_no"

# FE 경로
grep -A 40 "export const SCREEN_PATH" frontend/haccp-web/src/shell/tabRoute.ts

# BE 컨트롤러
grep -rn "RequestMapping" backend/haccp-api/src/main/java --include=*Controller.java
```
