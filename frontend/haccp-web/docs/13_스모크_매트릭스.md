## 5. 스모크 실행 방법

### 5.1 브라우저

1. `https://haccp.example.com` (또는 로컬 self-signed `https://127.0.0.1`) 접속  
2. 스모크 계정으로 로그인 (배포 직후 기본 계정은 **즉시 변경**)  
3. 위 표 순서대로 판정 칸 기입  

### 5.2 API 자동 (최소)

```bash
# 자격은 환경변수만 — 문서·git에 실값 금지
SMOKE_USER=... SMOKE_PASS=... bash scripts/prod_smoke.sh https://haccp.example.com
# 로컬 self-signed
SMOKE_INSECURE=1 SMOKE_USER=... SMOKE_PASS=... bash scripts/prod_smoke.sh https://127.0.0.1
```

Jenkins `Prod smoke` 스테이지가 동일 스크립트를 호출한다. 계정은 Credentials `haccp-smoke-user` (조회 전용).
