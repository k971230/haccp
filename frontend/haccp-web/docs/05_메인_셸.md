## 1. 셸이 하는 일

```
로그인 후 HaccpShell
 ├─ SideMenu — menuApi → 2단 트리 (대분류 h_menu_cd · leaf)
 ├─ 탭 바 — tabStore keep-alive
 ├─ 본문 — SCREEN_REGISTRY[scrnCd] 마운트
 ├─ 상단 명령 — pageCommands (조회/신규/저장/삭제 … 활성 페이지 등록분)
 ├─ useViewLog — UV/PV 버퍼 → collectViewLogs
 ├─ DialogHost — mesConfirm/mesToast
 └─ ShellFooter — 상태
```

홈 `/` → `HomeView` → 기본 `today-tasks` 오픈.

---

## 2. 메뉴 · 레지스트리

| 규칙 | 내용 |
|------|------|
| leaf 키 | DB `scrn_cd` = 레지스트리 키 **동일** |
| 미구현 | 레지스트리 없음 → `isImplemented` false → 메뉴 비활성(숨기지 않음) |
| HWP | `hwpLeaf(tmplCd)` → 공용 `HwpDocumentEditorPage` |
| 라우트 | `tabRoute.routeOf` → `/{moduleCd}/{screenCode}` |
| deep-link | `/screen/{scrnCd}?docIdx=` · `documentNav.routeForDocument` |

정리 표: [`07`](07_메뉴_화면_API_DB_전수.md)

---

## 3. 페이지 명령 (상단 버튼)

- 페이지: `usePageCommands({ search, new, save, delete, … })`
- 권한·업무에 따라 등록 생략 가능 (예: 법적서류는 **search만**)
- `PageScrnContext`로 활성 화면 코드 전달

---

## 4. 탭 · dirty

- `tabStore` — 다중 화면 keep-alive  
- `pageDirtyRegistry` / `useRegisterPageDirty` — 닫기·beforeunload  
- DocForm: `useDocFormSession`이 dirty 등록

## 5. UV/PV

| 단계 | 위치 |
|------|------|
