## 3. `useDocFormSession` 계약 (DB형 통합 핵심)

**파일:** `hooks/useDocFormSession.ts`  
**사용 페이지:** ColdMonitor · HygieneCheck · BizOpsForm · CcpForm · CcpGenericMonitor

| 멤버 | 역할 |
|------|------|
| `listRows` / `setListRows` | 좌측 목록 (C draft + 서버행) |
| `activeKey` / `activeBuffer` | 현재 편집 본문 |
| `replaceServerList(server, keyOf)` | 조회·저장 후 서버행 교체, draft 유지 |
| `addDraft(listSeed, buffer)` | 신규 C행 + 버퍼 |
| `selectRow(key)` | 좌측 클릭 → 버퍼 전환 |
| `markDirty()` | 본문 수정 → U |
| `updateActiveBuffer(patch)` | 버퍼 패치 |
| `removeDraft(key)` / 삭제 연동 | draft 제거 |
| `saveAll({ validate, saveOne, … })` | dirty 전건 검증 후 단건 save 순차 |
| dirty → `useRegisterPageDirty` | 탭 닫기 경고 |

페이지는 **양식별 buffer 타입·validate·saveOne만** 넘기고, 목록/버퍼/일괄저장 골격은 공유한다.

## 12. 분할·추가 원칙 (에이전트)

1. **Page = 조립자** — 새 UI 복붙은 `components/`로.  
2. **api = HTTP만** — toast/confirm 금지.  
3. **shell은 pages를 import하지 않음** — `screenRegistry`만 예외.  
4. DB형 작성은 **`useDocFormSession` + DocFormLayout** 재사용.  
5. HWP는 **`hwpLeaf` + HwpDocumentEditorPage** — 양식별 Page 복제 금지.  
6. CCP 금속검출·검증은 **`ccpFormsApi`** — 제거된 `ccpMetalApi`/`ccpVerificationApi` 재생성 금지 (2026-08-10, STEP 01).  
7. 삭제: FE `validate* → confirm → delete*` / BE 양쪽 `assertDeletable`.  
8. 매직 넘버 금지 → `envConfig` / `.env`.
