## 1. 삭제 표준 — [OPS_DELETE]

### 1-1. API

- HTTP **DELETE 금지** → `POST .../validate-delete` → `POST .../delete`
- Body: 복합키 객체 **배열** `[{ ... }]` (단건도 1건 배열). 스칼라 배열 금지
- 참조 차단: All-or-Nothing. 메시지  
  *"선택한 항목 중 {label} '{key}'이(가) {target}에서 참조 중이므로 삭제할 수 없습니다."*  
  (`DeleteValidation.throwIfBlocked`)

### 1-2. FE

```
resolveRowsForDelete → validateDeleteApi → mesConfirm → deleteApi → 재조회
useAsyncAction.run(fn, "del")
```

- `shell/resolveDelete.ts` · `shell/dialog.tsx` · `shell/errors.ts`
- M-D: 마스터/디테일 각각 위 흐름 (HACCP는 MES `masterDetailFocus` 없이 페이지별 `useSection`)

### 1-3. BE Double Check

- `validateDelete` **와** `delete` **양쪽**에서 `assertDeletable(coCd, keys)`
- `@Transactional` + SP 루프. SP 내부 자율 COMMIT 금지
- PG: Tuple IN / `<foreach>` 단일 쿼리 → `DeleteBlocker` (Service 루프 COUNT 금지)

**HACCP 골드:**  
`DocumentController` → `DocumentService.assertDeletable` → `DocumentMapper.selectDocumentDeleteBlocker`  
공통: `common/validation/DeleteValidation.java` · `DeleteBlocker.java`

## 2. API 타임아웃 3계층 — [OPS_TIMEOUT_TIER]

하드코딩 금지. FE: `.env` + [`config/envConfig.ts`](../src/config/envConfig.ts)

| 인스턴스 | env | 기본 | 용도 |
|----------|-----|------|------|
| `http` | `VITE_API_TIMEOUT_DEFAULT` | 10s | 일반 CRUD · validate-delete |
| `httpBatch` | `VITE_API_TIMEOUT_BATCH` | 60s | 대량·배치성 |
| `httpFile` | `VITE_API_TIMEOUT_FILE` | 120s | 업로드·다운로드·PDF·서명 |

신규 API는 체급에 맞는 인스턴스. 기본 `http`. 파일은 반드시 `httpFile` (`documentApi` 등).

---

## 3. 4중 방어 — [OPS_TIMEOUT_DEFENSE] (배치 60s 기준)

1. **FE** — Dim·스피너, 초과 시 연결 끊고 업무 안내  
2. **Nginx** — `proxy_read_timeout` ~70s (Grace)  
3. **Spring** — `TX_DEFAULT_TIMEOUT_SECONDS=60` · CUD `@Transactional`  
4. **MyBatis** — `MYBATIS_STATEMENT_TIMEOUT_SECONDS=60`

파일/PDF: FE 120s · `APP_RHWP_TIMEOUT_SECONDS`는 그보다 짧게(예: 110).

## 4. 전역 설정 — [OPS_GLOBAL_CONFIG]

소스 매직 넘버 금지 → env / yml / `envConfig.ts`.

| FE env | 기본 | 용도 |
|--------|------|------|
| `VITE_GRID_DEFAULT_PAGE_SIZE` | 50 | 예약(클라 페이징 없음) — G-23 |
| `VITE_GRID_VIRTUAL_THRESHOLD` | 100 | Mes*Grid 가상화 임계 |
| `VITE_SEARCH_DEBOUNCE_MS` | 300 | 검색 디바운스 |
| `VITE_API_RETRY_COUNT` | 2 | GET 재시도 |
| `VITE_DASHBOARD_POLLING_MS` | 10000 | 폴링 |
| `VITE_VIEW_LOG_FLUSH_MS` | 30000 | UV 버퍼 flush |
| `VITE_TOAST_*_MS` | 2600 / 5000 | 토스트 |

`.env` 변경 후 Vite **재시작**. 커밋은 `.env.example`만.

BE: `JWT_*` · `LOGIN_MAX_FAIL_COUNT` · `APP_FILE_*` · `APP_RHWP_*` · `*_CRON` · `CORS_*` — [`backend/haccp-api/.env.example`](../../../backend/haccp-api/.env.example)
