## 하위
- `api/` — Axios HTTP 클라이언트·도메인 API 함수
- `components/` — 공용 UI·그리드·폼·문서·레이아웃 컴포넌트
- `config/` — envConfig 등 전역 상수(매직넘버 금지)
- `hooks/` — 공용 React hooks
- `lib/` — 라이브러리 래퍼·유틸 모듈
- `pages/` — 화면 페이지(메뉴 도메인별)
- `routes/` — React Router·SCREEN_REGISTRY 연동
- `shell/` — HaccpShell·탭·메뉴·세션·에러 셸
- `stores/` — Zustand 등 클라이언트 상태
- `styles/` — 전역·테마 CSS
- `types/` — 공유 TypeScript 타입
- `utils/` — 순수 유틸 함수
