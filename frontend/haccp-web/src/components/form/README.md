# form

폼·입력 공용 컴포넌트.

HTML 양식 표는 화면 폴더의 Paper 가 그린다. 여기서는 서명 칸·props 만 둔다.

| 파일 | 역할 |
|---|---|
| `htmlFormPaperShared.tsx` | `HtmlFormPaperProps` · `SignSlot` · `PaperTitleCell` |
| `DocFormLayout.tsx` · `DocFormSearchToolbar.tsx` | 작성 화면 셸 |

기준관리 5화면은 `HtmlFormTemplatePage` 50:50 프레임. 표준은 수정 불가, 자사는 행추가만.
