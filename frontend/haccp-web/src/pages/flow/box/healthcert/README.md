# 보건증관리 (`health-cert-management`)

URL `/flow/box/health-cert-management`. 문서함 아래.

## 처리 근거

식품위생법 제40조 · 식품위생 분야 종사자 건강진단 규칙. 민감정보(건강)이며
결과서 서식에 주민번호가 있을 수 있다. 별도 동의 화면은 두지 않는다 — 법령상 이행 관리.

## 화면이 지키는 것

- 좌: 보건증 대상 사원. 임박 필터는 알림 설정 MAX 일수
- 우: 이력 + PDF. 열람은 새 탭. 가림 체크 없이 저장 불가
- 주민번호는 DB 에 두지 않는다. 뒷자리가 보이게 올리지 말 것
- 열람은 본인 또는 담당자. ADMIN 이라도 담당자가 아니면 타 직원 파일을 못 연다
- 삭제는 담당자만 — 정보주체가 최신 증빙을 지워 법령 이행을 숨기지 못하게
- 담당자 지정은 ADMIN 만. 담당자는 열람·삭제·캘린더만
- 알림은 크론이 `tbl_notification` 에 넣고, 이 화면 상단에 미읽음을 보여 준다
- 대체된 이전 이력은 만료일로부터 2년(`APP_HR_RETENTION_DAYS`) 후 파기. 최신 1건은 남긴다
- 업로드는 `{uuid}.pdf.tmp` 에 다 쓴 뒤 rename. 키 세대는 `key_version`
