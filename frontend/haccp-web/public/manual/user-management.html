1-2. 사용자관리

/sys/code/user-management

터치무엇
1행추가
2사용자 ID — 로그인에 쓸 아이디
3사용자명
4권한그룹 칸의 버튼 → 팝업에서 고른다 (ADMIN · HACCP_MASTER · HACCP_TEAM · VIEWER …)
5부서 칸의 버튼 → 팝업에서 고른다. 비워도 된다
6비밀번호를 넣는다
7저장

필수는 사용자 ID · 사용자명 · 권한그룹 셋입니다. 부서는 비워도 됩니다.

비밀번호를 바꿀 때 — 비밀번호 칸에 새 값을 넣고 저장합니다. 비워 두면 지금 비밀번호가 그대로 유지됩니다. 빈칸으로 저장해도 지워지지 않습니다.

1-2-1. 서명 등록 — 빼먹으면 안 되는 것

종이(지면)의 결재 도장칸에 그림 서명이 찍히게 하려면 사람마다 서명을 올려야 합니다. 안 올리면 이름 글자가 대신 찍힙니다. 고장이 아니라 설계지만, 서류로는 서명이 낫습니다.

터치무엇
1표에서 그 사람 줄을 고른다
2서명 칸의 버튼을 누른다
3업로드 (이미 있으면 「서명 교체」)
4파일을 고른다 — PNG 또는 JPG, 10MB 이하
5닫기
막히는 자리
  • 저장하지 않은 새 줄에는 서명을 못 올립니다. 먼저 저장하고 그 줄을 다시 고릅니다
  • PNG·JPG 가 아니면 막힙니다
  • 지울 때는 같은 팝업의 삭제
