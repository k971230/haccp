다섯 화면 조작이 같습니다. 왼쪽 양식 목록, 오른쪽 지면(종이 모양).

표준 양식을 우리 것으로 복사해 고친다
터치무엇
1왼쪽 행추가 — 표준 양식을 복사한 새 양식이 생긴다
2양식명을 우리 이름으로 바꾼다
3왼쪽 저장
4오른쪽 지면 위 수정
5지면의 제목·점검항목·한계기준을 고친다. 항목을 늘릴 때는 표 오른쪽 끝 행추가
6오른쪽 저장 (되돌리려면 취소)
7왼쪽 목록에서 사용여부를 사용으로 두고 왼쪽 저장
막히는 자리
  • 표준 양식(코드가 _000 으로 끝나는 것)은 못 고치고 못 지웁니다. 항상 미사용입니다. 반드시 복사해서 씁니다
  • 새로 만든 양식은 기본이 사용입니다
  • 양식명은 필수입니다
  • 저장 안 한 새 줄이 있으면 또 행추가할 수 없습니다. 저장하거나 지웁니다
  • 여기서 사용여부를 사용으로 두지 않으면 작성 화면의 양식 선택 팝업에 안 나옵니다
  • 점검항목이 하나도 없으면 저장이 막힙니다 — 「점검항목을 한 줄 이상 넣으세요」
