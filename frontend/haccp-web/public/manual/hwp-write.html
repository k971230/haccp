2-3. 한글(HWP) 일지 작성

/draft/hwp-doc/hwp-write

왼쪽은 앞의 5화면과 똑같습니다. 오른쪽만 한글 편집기입니다.

터치무엇
1왼쪽 행추가
2「오늘 할일 — HWP 문서주기」 팝업이 뜬다. 오늘 쓸 HWP가 없으면 이 팝업 없이 바로 양식 선택
3주기와 상관없이 아무 양식이나 쓰려면 취소 (양식 직접 선택) → 양식 선택 팝업으로 넘어간다
4왼쪽 저장
5오른쪽 한글 편집기에서 문서를 채운다 — 글꼴·표·정렬 도구가 다 있다
6오른쪽 작성 후 저장 — 본문이 함께 올라간다
7오른쪽 전송
막히는 자리
  • 문서를 여는 동안 상태줄이 「문서를 여는 중입니다…」로 바뀝니다. 이게 끝나기 전에 다른 줄을 누르지 않습니다
  • 한글 문서는 일자만 맞으면 전송됩니다. 본문이 한글 파일이라 시스템이 그 안의 점검 항목을 읽지 못합니다. 그래서 빈칸을 대신 잡아 주지 않습니다 — 다 채웠는지는 사람이 봐야 합니다
  • 이탈여부는 지면이 아니라 왼쪽 목록의 체크 칸입니다. 켜고 저장하면 개선조치가 생깁니다. 실제 조치 내용은 이탈·개선조치 화면에서 적습니다. 다시 끄면 조치가 지워지지만, 이미 조치를 적어 둔 건은 지워지지 않습니다

이 화면의 칸마다 들어가는 값

D-8. 일지 작성 — 전송이 보는 것

여기가 가장 중요합니다. 전송을 누르면 아래를 전부 봅니다.

지면 종류필수안내문
모든 지면일자「일자를 입력하세요」
항목형 — 일반위생 · CCP 검증판정 · 값 칸 전부「(항목명)을 입력하세요」
기록표형 — 포장 · 가열 · 금속검출각 줄의 시각「n번째 기록 행의 시각을 입력하세요」
기록표형각 줄의 판정「n번째 기록 행의 판정을 선택하세요」
기록표형각 줄의 품명「n번째 기록 행의 품명을 입력하세요」
한글(HWP) 문서일자만—

기록 표에서 필수는 시각 · 판정 · 품명 셋입니다. 설비명·비고는 비어도 전송됩니다. 영역 첫 줄은 품명 자리가 라벨이라 비워 둡니다.
