# bas

도메인 `bas` — 기준정보(마스터·설비/방충 이력). Controller·Service·Mapper 인터페이스.

손대는 메뉴는 sys와 같이 `com.haccp.bas.{메뉴}` 로 분할한다. 미리 전 메뉴를 나누지 않는다. 골드: `com.haccp.sys` · `08-haccp-backend.mdc`.

사용양식·문서주기는 `com.haccp.hwp` 영역이다.

## 공유

- `dto/` — 아직 평탄한 화면(마스터·이력)의 요청·응답 DTO
