HACCP API 루트 패키지. 화면은 `com.haccp.{대}.{중}`. 경로 정본 `docs/24_URL_DB_폴더_패키지_정본.md`.

## 하위
- `auth/` · `menu/` · `code/` · `pref/` · `log/` · `common/` — 셸
- `docs/` — 문서 (`ccp` · `prp` · `hwp` · `sch` · `html` · `document` · `template`)
- `flow/ca/` — 개선조치
- `bas/master/` — 기초정보 마스터
- `sys/code/` · `sys/logs/` — 시스템
- `tsk/` — 오늘 할 일
- `workflow/` — 결재·양식 공용
