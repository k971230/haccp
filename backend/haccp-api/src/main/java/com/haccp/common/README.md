# common

공통 설정·컨텍스트·예외·응답·검증.

## 하위
- `config/` — Security·CORS·JWT 필터·WebMvc 등 Spring 설정
- `context/` — LoginUser 등 요청 스코프 컨텍스트
- `exception/` — BizException·GlobalExceptionHandler·사용자 메시지
- `response/` — 공통 API 응답 래퍼
- `validation/` — 삭제 검증(DeleteValidation) 등 공통 검증
