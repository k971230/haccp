# mapper/bas

MyBatis XML — `bas` (기준정보). 손대는 메뉴는 `mapper/bas/{메뉴}/` 로 나눈다. `namespace`는 인터페이스 FQCN.

사용양식·문서주기는 `mapper/hwp/` 이다.

## 아직 평탄

`MasterMapper.xml` · `EquipmentHistMapper.xml` · `PestDeviceHistMapper.xml` — 그 메뉴를 손볼 때 폴더로 옮긴다.
