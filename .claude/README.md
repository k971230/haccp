# .claude

Claude Code 전용 실행 설정이다. **규칙 정본은 아니다** — 정본은 `.cursor/rules/` 다
([`CLAUDE.md`](../CLAUDE.md)). 여기에는 도구 기능(서브에이전트·슬래시 명령)으로만
표현되는 것을 둔다.

| 경로 | 맡는 것 | 안 맡는 것 |
|---|---|---|
| `agents/doc-critic.md` | 문서 결함 후보 추출 (읽기만) | 근거 조사 · 문서 수정 |
| `agents/doc-defender.md` | 저장소 실물 근거로 방어·인정 (읽기만) | 문서 수정 |
| `commands/doc-audit.md` | `/doc-audit <문서경로>` — 검수 루프 절차. **md 만 고친다** | 코드 패치 · 프로젝트 코딩 규칙 |

서브는 둘, 쓰는 손은 메인 하나다. 공식 문서상 한계는 동시 20 · 중첩 3층 ·
전체 `description` 합계 15,000 토큰이라 여기에 걸릴 일은 없다.
늘려야 할 이유가 생기기 전에는 늘리지 않는다.

판정 어휘는 네 가지다 — **결함**(코드가 문서대로 동작하지 않는다) ·
**결함 아님**(코드가 문서에 적힌 대로 동작한다) ·
**재확인 대기**(코드로는 맞는데 실행 환경을 안 봤다) ·
**단정 불가**(근거가 저장소에 없다). `agents/doc-defender.md` 가 같은 넷을 쓴다.

**기본:** 검수는 md 만 고치고 코드는 보고만 한다. 2026-09-03 확정 —
[`docs/8_결정_이력.md`](../docs/8_결정_이력.md).
