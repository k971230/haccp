# 운영 전 문서 검수 루프

대상 문서: `$ARGUMENTS`

경로가 안 넘어왔으면 **되묻고 멈춘다.** 아무 문서나 고르지 않는다.

## 배역

| 역 | 누구 | 권한 |
|---|---|---|
| Critic | 서브에이전트 `doc-critic` | 읽기만. 결함 후보만 |
| Defender | 서브에이전트 `doc-defender` | 읽기만. 근거만 |
| Supervisor | 메인 | 판정 · 문서 수정 · 파일 정리 |

서브는 둘이고 순차다. 병렬로 늘리지 않는다 — A 의 지적이 나와야 B 가 방어한다.
서브는 문서를 안 고친다. **쓰는 손은 메인 하나뿐이다.**
메인도 **문서만** 고친다. 코드·생성기·SP·시드는 이 루프에서 쓰지 않는다.
코드 결함은 `handoff.md` 「아직 안 고친 것」에 올리고, 패치는 사용자가 따로 지시할 때.

## 한 라운드

1. `doc-critic` 호출 — 대상 문서 경로와 **지난 라운드 판정 목록**(번호·제목·판정)을 같이 준다
2. `doc-defender` 호출 — Critic 이 낸 지적 원문을 그대로 준다
3. 메인이 건별 판정하고, `결함` 인 것만 문서에 반영한다

`재확인 대기` · `단정 불가` 는 **문서를 안 고친다.** 문서 끝 「미결」 절에 한 줄로 남긴다.
근거 없는 지적을 반영하는 게 이 루프에서 가장 흔한 사고다.

## 종료 (하나라도 걸리면 즉시)

1. Critic 이 `결함 없음` 을 냈다
2. 이번 라운드에 의미 있는 문서 변경이 없다 (서식·띄어쓰기만 바뀐 건 변경이 아니다)
3. 같은 이슈가 2회 이상 오갔다 — 메인이 결론 내고 닫는다
4. 30라운드

## 파일 정리

라운드가 남긴 쓰레기만 지운다.

- **먼저 안 만든다.** 편집 전 백업본(`*_backup.md`, `구버전_*.md`)을 만들지 않는다. git 이 백업이다.
  라운드 기록도 파일로 안 뺀다. 터미널 요약이 기록이다
- 지우는 것: `temp_*.md` · `tmp_*.md` · `old_*.md` · `*_backup.md` · `round[0-9]*.md`
  중 **이번 검수가 만들었거나 명백히 그 파편인 것**
- 안 지우는 것: README 나 색인이 가리키는 파일 · 이름만 비슷한 실제 문서 ·
  `docs/**` 생성기 산출물 · 판단이 갈리는 것 전부. 갈리면 지우지 말고 목록에만 올린다
- git 추적 중이면 `rm` 대신 `git rm` — 이력에 남아야 되돌린다

## 출력

라운드마다 터미널에 세 줄씩.

```
[R{n}] A: <지적 제목 목록>
      B: <건별 판정 한 줄>
      판정: <반영 N건 / 기각 M건> — <반영한 것 요약>
```

끝나면 요약 하나.

```
[최종 운영 검수 요약]
- 대상 문서: <경로> (저장 완료)
- 종결 라운드: <n> / 종결 사유: <위 1~4 중 하나>
- 반영: <건수> · 미결: <건수>
- 삭제한 파일: <목록 또는 없음>
```

3라운드를 넘겨도 안 수렴하면 사유에 그 이유를 적는다. 대개 문서가 아니라 코드가 흔들리는 중이다.
